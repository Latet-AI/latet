## Was Latet schützt

KI-Agenten lesen für Sie, und autonome Agenten wie Hermes Agent, OpenClaw, Goose und OpenHands tun
das selbstständig, stundenlang, ohne dass jemand jeden Schritt mitliest. Jede Anfrage wird geprüft,
bevor sie den Rechner verlässt, ganz gleich, wodurch der Text in sie gelangt ist:

| Was Ihren Rechner verlässt | Zum Beispiel | Was Latet tut |
| --- | --- | --- |
| Ihre Prompts | *"Sende die IBAN <span class="real">GB82 WEST 1234 5698 7654 32</span> an <span class="real">Emily Carter</span>"* | Jeder Wert wird zu einem Ersatzwert im selben Format, der Name mithilfe des optionalen lokalen Namensmodells; die Antwort kommt mit den echten Werten zurück |
| Dateien, die der Agent liest | `.env`, `config.yaml`, Test-Fixtures, ein Kundenexport | Schlüssel, Passwörter, Verbindungszeichenfolgen und personenbezogene Daten werden maskiert; Dateien, die der Agent schreibt, erhalten die echten Werte zurück |
| Befehlsausgaben und Logs | `docker logs`, ein Stacktrace, `kubectl describe` | Tokens, E-Mail-Adressen, öffentliche IP-Adressen und Identifikationsnummern darin werden maskiert |
| Datenbankabfragen | `psql` oder ein MCP-Server, der auf `SELECT * FROM customers` antwortet | Spalten mit geheimen Werten immer; im [strikten Datenmodus](concepts/production-data/) jeder Wert, mit Ersatzwerten, bei denen Joins und Zählungen weiterhin funktionieren |
| Webseiten | Ein Admin-Panel, das der Agent mit einem Browser-Tool öffnet | Die personenbezogenen Daten im Text der Seite werden maskiert |
| Anweisungen | CLAUDE.md, AGENTS.md, der System-Prompt | Ihr Name, Ihr Benutzername, Ihr Hostname und die Domain Ihres Unternehmens werden maskiert |
| Verlauf | Eine Sitzung, die zehn Tage später fortgesetzt wird | Derselbe Wert erhält jedes Mal denselben Ersatzwert |
| Screenshots | Der Screenshot einer Rechnung | Mit der optionalen [Texterkennung](concepts/images/) wird der Text darin auf Ihrem Rechner gelesen und jeder Wert mit seinem Ersatzwert überdeckt; PDFs werden markiert oder nicht gesendet (`images: block`) |
| Was kein Muster erkennt | *"Mark aus dem Vertrieb führt heimlich Vorstellungsgespräche bei einem Konkurrenten"* | Der optionale [lokale Prüfer](concepts/llm-review/), Ihr eigenes Sprachmodell, findet es, bevor es den Rechner verlässt, nach den Anweisungen von Latet und [Ihren eigenen Hinweisen](concepts/llm-review/#ihre-hinweise): was in Ihrer Arbeit als sensibel gilt, überall oder in einem einzelnen Projekt |

## Wie Latet schützt

<CardGrid>
	<Card title="Erkennt, bevor etwas den Rechner verlässt" icon="magnifier">
		Geheime Werte (API-Schlüssel, Tokens, Passwörter, private Schlüssel, Zugangsdaten in
		Verbindungszeichenfolgen), personenbezogene Daten (E-Mail-Adressen, Telefonnummern, IBANs,
		Kartennummern, Umsatzsteuer-Identifikationsnummern, die Identifikations- und Steuernummern von
		15 Ländern), Ihre eigenen Begriffe und Formate und die Identität dieses Rechners.
	</Card>
	<Card title="Setzt realistische Ersatzwerte ein" icon="random">
		Jeder Wert wird zu einem deterministischen Ersatzwert im selben Format, jedes Mal demselben,
		sodass Code und Konfiguration für das Modell weiterhin Sinn ergeben.
	</Card>
	<Card title="Stellt auf Ihrem Rechner wieder her" icon="laptop">
		Die Originale werden lokal wieder eingesetzt, in Antworten, gestreamten Ausgaben und den
		Argumenten von Tool-Aufrufen, sodass die Dateien, die Ihr Agent schreibt, die echten Werte
		enthalten.
	</Card>
	<Card title="Passt sich jedem Projekt an" icon="setting">
		Eine `latet.yaml` in einem Repository ergänzt die eigenen Begriffe und Formate des Projekts,
		geteilt mit dem Team, und kann den Schutz nie verringern.
	</Card>
	<Card title="Liest Daten anhand ihrer Struktur" icon="document">
		Spalten mit geheimen Werten in einem Abfrageergebnis werden immer maskiert, und der strikte
		Datenmodus maskiert jeden Wert der Tabellen, des JSON und der Logs, die ein Agent liest.
	</Card>
	<Card title="Prüft, was kein Muster erkennt" icon="approve-check-circle">
		Wenn Sie möchten, liest ein Sprachmodell auf einem Ihrer Server jeden Text, bevor er den
		Rechner verlässt: beiläufig erwähnte Namen, Gesundheitsangaben, ein Passwort, das in einem
		Satz steht.
	</Card>
	<Card title="Zeigt Ihnen die Belege" icon="list-format">
		Ein lokales [Dashboard](dashboard/) zeigt genau, was an den Anbieter gesendet wurde und wie
		jeder Wert maskiert wurde.
	</Card>
</CardGrid>

## Sehen Sie, was Ihren Rechner verlassen hat

`latet dashboard` öffnet eine lokale Seite mit jeder Anfrage, die Ihre Agenten gesendet haben: das
Original auf Ihrem Rechner neben dem, was das Modell erhalten hat, und bei jedem maskierten Wert, was
er ist und welche Regel ihn gefunden hat.

## Agenten

| Agent | Wie er über Latet läuft |
| --- | --- |
| [Claude Code](agents/claude-code/): CLI, VS Code, JetBrains, mit einem Pro- oder Max-Abonnement oder einem API-Schlüssel | Client-Modus: Das Latet-Plugin maskiert in Claude Code; der Daemon prüft jede Anfrage |
| [Codex](agents/codex/): CLI und Desktop, mit ChatGPT oder einem API-Schlüssel | Gateway: Der Daemon maskiert und setzt die echten Werte wieder ein |
| [OpenCode](agents/opencode/), mit Anbietern, die per API-Schlüssel angebunden sind | Gateway |
| [Gemini CLI](agents/gemini/), mit einem API-Schlüssel oder Vertex AI | Gateway, mit `latet gemini` |
| [Hermes Agent, OpenClaw, Goose, OpenHands](agents/autonomous-agents/) und jeder Agent, der eine OpenAI-kompatible Base-URL akzeptiert | Gateway, mit Ihrem API-Schlüssel von OpenAI, OpenRouter oder Anthropic; Hermes auch mit Anmeldung über ChatGPT |
| [Skripte und SDKs](agents/openai-compatible/): die SDKs von OpenAI, Anthropic und Google GenAI, LangChain, LangGraph, AutoGen, CrewAI, Aider usw. | Gateway, mit `latet run` |
| [GitHub Copilot, JetBrains, Zed und andere Tools](agents/other-tools/): Copilot in VS Code und seine CLI, Junie CLI, JetBrains AI Assistant, Zed, Cline, Kilo Code, Continue, Qwen Code, Crush | Gateway, mit Ihrem API-Schlüssel; die Inline-Vorschläge von Copilot sind nicht abgedeckt |

Nicht abgedeckt: Chat und Cowork in Claude Desktop mit Anmeldung bei Claude, Cloud-Sitzungen,
Cursor, Windsurf und die anderen Tools, deren Anfragen von den Servern des Herstellers ausgehen:
siehe [was Latet nicht schützen kann](agents/other-tools/#was-latet-nicht-schützen-kann).
