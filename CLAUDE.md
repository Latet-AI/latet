# Latet: notes for Claude

- **Every language, every time.** The dashboard and the documentation come in English, Italian,
  German, French and Spanish, with English as the reference. A fix or a new feature that adds or
  changes a user-facing string (`dashboard/src/locales/`) or a documentation page
  (`docs/src/content/docs/`) updates all five languages in the same change, never English alone.
  Screenshots that show the change are regenerated in every language too.
